Backup & export

Save a copy

A backup file holds everything (work orders, moulds, hours, procedures, inventory, to-do lists, unassigned updates) and can be imported again. The CSV opens in Excel or Google Sheets.

A full backup is also saved to the _Backups folder in your Drive Work Orders folder once a week, automatically (the newest 8 are kept).

Your log is empty. Import the export file from the previous version to bring your work orders across.
Work order numbers already in the app are skipped, so importing never overwrites anything.
Export your entries from Diarium as HTML (brings the photos too) or JSON (text only) and pick the file here. Photos upload to the _Unassigned Drive folder and move with each update when you assign it. Big exports are best done a month or so at a time. Each entry (or each heading inside an entry) goes into Unassigned updates with its Diarium date, with a suggested work order where the app can tell. Nothing is assigned or created until you say so, and importing the same file twice won't double up.
